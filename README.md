# 🚆 Mumbai Local Deluxe

A single-file cinematic web app recreating a Mumbai local train ride — animated rain, moving scenery, and a built-in YouTube/Spotify music player.

## Features
- Animated SVG train interior with rain & scenery
- YouTube playlist player + Spotify embeds
- Paste your own YouTube/Spotify playlist link
- Live IST clock, no build step, no dependencies

## Usage
Open `index.html` in your browser. Switch sources via the top bar, load playlists via the chips, or click **+ Custom URL** to add your own.

## Tech
Pure HTML/CSS/JS + YouTube IFrame API + Spotify embed. Fonts: Rozha One, Teko, Poppins.
